# Responsible Control

**Responsible Control** — концептуальная бренд-, информационная и сервисная система для регулируемого обращения алкоголя, никотина, лекарств, каннабиса и других психоактивных продуктов.

Это не бренд вещества и не концепт «магазина наркотиков». Это public-interest design-проект: единая consumer-facing грамматика, которая помогает понять продукт, риск, условия доступа и путь к помощи, но структурно не создаёт спрос и не стигматизирует человека.

> Ясность без давления.

## Три непереговорных условия

1. Не стимулировать употребление.
2. Не скрывать значимую информацию.
3. Не стигматизировать человека.

## Состав MVP

- 3 семейства упаковки × 2 условных варианта;
- фрагмент регулируемой точки 1:1;
- 7 основных digital-экранов;
- карточка продукта, сравнение, чек, отказ, помощь и отзыв;
- 5 сервисных сценариев;
- три сравниваемые среды: commercial, hostile plain и Responsible Control;
- 55 редактируемых слайдов, включая 31 solution frame с заданным объектом, ракурсом и функцией.

## Статус

`v0.2-atlas`, 2026-10-07. Это рабочая гипотеза для прототипирования, не юридический, медицинский или строительный стандарт. Юрисдикция, реальные продукты, пороги риска, клинические тексты, публичное имя и финальный знак остаются открыты.
