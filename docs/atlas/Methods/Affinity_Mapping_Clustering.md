# AFFINITY MAPPING & CLUSTERING — группировка материала

[← Methods Overview]({{ site.baseurl }}/atlas/Methods/METHODS_OVERVIEW.html)

## Method Definition

### Purpose

Организовать разрозненные наблюдения, цитаты и findings в смысловые группы, сохраняя происхождение каждой единицы, неоднозначность и исключения. Affinity Mapping и прежний Insight Clustering объединены как два масштаба одной процедуры: первичная группировка и последующее укрупнение/интерпретация групп.

### Categories

- Synthesis / Analysis

### Use When

- material set слишком велик или разнороден для непосредственного синтеза;
- нужно обнаружить bottom-up patterns между несколькими источниками;
- требуется подготовить прозрачное основание для Insight Synthesis.

### Do Not Use When

- исходные записи уже являются неподкреплёнными выводами и теряют связь с evidence;
- заранее заданные категории не допускают неожиданных групп;
- частота автоматически принимается за значимость;
- противоречащие и одиночные данные удаляются ради чистой картины.

### Required Inputs

- Project Question и границы material set;
- атомарные записи с source ID;
- единица группировки и правила доступа к чувствительным данным.

### Process

1. Разбить материал на атомарные units, не теряя source ID и контекст.
2. Выполнить первичную bottom-up группировку по смысловой близости.
3. Дать группам описательные, а не стратегические названия.
4. Отметить overlaps, contradictions, outliers и ungrouped items.
5. При необходимости объединить близкие группы в более крупные clusters.
6. Сформулировать patterns как кандидаты для дальнейшего синтеза, не как готовые решения.

### Limitations

- группировка зависит от исследовательского суждения;
- визуальная близость карточек не доказывает причинную связь;
- крупный источник может получить непропорциональный вес;
- редкие данные могут быть стратегически важнее частых.

## Граница владения

Метод хранит units, группировку и provenance. Insight формулируется в Insight Synthesis либо соответствующем анализе. Группа не становится каноническим finding автоматически.
