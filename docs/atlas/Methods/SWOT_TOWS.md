# SWOT / TOWS — сопоставление стратегических факторов

[← Methods Overview]({{ site.baseurl }}/atlas/Methods/METHODS_OVERVIEW.html)

## Method Definition

### Purpose

Разделить относящиеся к вопросу внутренние сильные/слабые стороны и внешние возможности/угрозы, а затем сопоставить конкретные факторы в TOWS для получения вариантов действий, требующих дальнейшего выбора и проверки.

### Categories

- Synthesis / Analysis
- Strategy

### Use When

- доступны evidence-backed внутренние и внешние факторы;
- полезно увидеть их взаимодействие, а не отдельные списки;
- Project Question требует вариантов стратегического ответа.

### Do Not Use When

- общие прилагательные заполняют четыре клетки без источников;
- internal/external boundary не определена;
- opportunity понимается как любое желание, а threat — как любой страх;
- TOWS-вариант объявляется принятой стратегией автоматически.

### Required Inputs

- Project Question и граница анализируемого субъекта;
- сведения из Audit, Research, PEST или других источников;
- статус, период и ограничения каждого фактора.

### Process

1. Собрать относящиеся к вопросу factors с source links.
2. Проверить internal/external classification и отделить факт от интерпретации.
3. Дать факторам стабильные IDs.
4. Сопоставить только содержательные пары/комбинации SO, ST, WO и WT.
5. Сформулировать action options, условия и риски.
6. Передать выбранные варианты в соответствующий канонический процесс решения.

### Limitations

- четыре категории упрощают динамические связи;
- один factor может быть условно сильной и слабой стороной в разных контекстах;
- полнота списка недостижима и не требуется;
- матрица не оценивает осуществимость без дополнительных данных.

### Source / School

SWOT analysis and TOWS strategic matching. Конкретная адаптация или источник указывается в Application Record при необходимости.

## Граница владения

Метод хранит factors, matrix и action options. Audit и Research сохраняют первичные наблюдения; канонический стратегический раздел принимает собственное решение со ссылкой на конкретный option. SWOT / TOWS не является частью Audit и не обязателен каждому проекту.
