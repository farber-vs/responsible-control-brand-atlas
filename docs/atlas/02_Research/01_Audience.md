# AUDIENCE — люди и ситуации

Система не ищет конверсионную ЦА. Сегментация нужна для доступности и пропорциональности.

| Группа / ситуация | Задача | Обязательство системы |
|---|---|---|
| Сформированное намерение | Получить конкретный допустимый тип | Точность, сравнение, быстрый путь |
| Только информация | Понять продукт, правило или риск | Доступ без покупки и, где возможно, ID |
| Проблемное употребление | Найти следующий шаг | Приватная независимая помощь |
| Языковой/когнитивный барьер | Получить критическую информацию | Plain language, подписи, аудио, человек |
| Инвалидность | Пройти тот же путь | Universal design без худшего отдельного маршрута |
| Сотрудник | Информировать, выдать или отказать | Сценарии, обучение, отсутствие sales-KPI |
| Оператор / регулятор | Поддерживать качество | Разделение ролей и публичный аудит |
| Сообщество вокруг точки | Понимать функцию и влияние | Нерекламный фасад и канал жалобы |
| Нет права доступа | Получить информацию, не продукт | Знание и помощь не закрываются |
