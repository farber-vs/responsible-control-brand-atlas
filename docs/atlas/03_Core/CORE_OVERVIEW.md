## Конфликт

Легальный канал должен быть достаточно понятным и уважительным, чтобы не проигрывать нелегальному, но не настолько привлекательным, чтобы создавать новый спрос.

## Предательство ядра

Endorsement продукта знаком системы; рост узнаваемости без понимания; luxury под видом нейтральности; унижение как сдерживание; скрытая реклама под видом образования; решение без источника и теста.

**Статус:** core hypothesis `v0.2`, принята для MVP.
