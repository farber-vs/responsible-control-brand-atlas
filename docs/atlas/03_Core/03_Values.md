# VALUES — ценности

| Ценность | Смысл | Поведение |
|---|---|---|
| Ясность | Значимое видно и сопоставимо | Понимание важнее декора |
| Соразмерность | Контроль соответствует риску | Ни карательности, ни маскировки риска |
| Достоинство | Человек не равен продукту или подозрению | Privacy, доступность, спокойный отказ |
| Независимость | Consumer-язык не принадлежит продавцу | Риск и сервис проходят независимую редакцию |
| Проверяемость | Решение имеет источник и версию | Неизвестное обозначается; ошибка исправляется |
| Обратимость | Стандарт можно остановить при вреде | Редизайн запускает проблема, не тренд |

## Итог

> **Ясность, соразмерность, достоинство, независимость, проверяемость и обратимость** образуют рабочую этику системы. Каждая ценность выражается наблюдаемым правилом, а не рекламным словом.
