# CULTURAL CODE MAPPING — карта культурных кодов

[[Methods/METHODS_OVERVIEW|← Methods Overview]]

## Method Definition

### Purpose

Сопоставить повторяющиеся культурные значения, нормы, роли, ритуалы и сюжетные конструкции в выбранном поле, показать их проявления и конфликты и определить предел применимости каждого кода.

### Categories

- Research
- Synthesis / Analysis

### Use When

- требуется перейти от отдельных semiotic observations к структуре поля;
- категория связана с принадлежностью, статусом, ритуалом или культурной памятью;
- один и тот же знак или сюжет меняет значение между группами.

### Do Not Use When

- код понимается как эстетический тег без социального контекста;
- архетипическая схема подменяет evidence;
- популярность кода автоматически трактуется как рекомендация бренду;
- карта используется для присвоения культурной принадлежности, которой у бренда нет.

### Required Inputs

- semiotic, historical, media, interview or ethnographic materials;
- Project Question, группы, территория и период;
- явные критерии, по которым наблюдения объединяются в код.

### Process

1. Собрать manifestations из нескольких типов источников.
2. Сгруппировать повторения по значению и социальной функции, а не только по внешнему виду.
3. Описать носителей, контекст, норму, противоположный код и конфликт.
4. Проверить историческую и групповую вариативность.
5. Сформулировать карту и только затем — проектные implications как гипотезы.

### Limitations

- культурные коды не являются фиксированными свойствами группы;
- карта отражает позицию и выбор источников исследователя;
- один corpus не показывает все субкультуры и контексты;
- применение кода брендом может быть неуместным даже при его узнаваемости.

## Граница владения

Semiotic Analysis разбирает производство значения в конкретных объектах; Cultural Code Mapping сопоставляет повторяющиеся значения и социальные функции между материалами. Выбранная роль или narrative бренда принимается в соответствующем каноническом разделе, а не автоматически выводится из карты поля.
