# INSIGHT SYNTHESIS — синтез объясняющих findings

[[Methods/METHODS_OVERVIEW|← Methods Overview]]

## Method Definition

### Purpose

Сопоставить findings из нескольких источников и сформулировать ограниченные объясняющие insights, которые связывают наблюдаемый pattern с возможным механизмом и имеют значение для дальнейшего решения.

### Categories

- Synthesis / Analysis

### Use When

- материал уже собран и имеет provenance;
- несколько источников описывают связанные явления;
- требуется перейти от списка наблюдений к объясняющим кандидатом для [[02_Research/05_Synthesis|Research → Synthesis]].

### Do Not Use When

- сырые данные ещё не разобраны или их происхождение потеряно;
- «глубокая причина» придумывается ради выразительной формулировки;
- противоречивые данные исключаются вместо ограничения insight;
- implication объявляется принятым стратегическим решением.

### Required Inputs

- Project Question;
- findings и source links из методов/Audit/Research;
- известные противоречия, пробелы и границы выборки.

### Process

1. Собрать findings, а не копировать весь raw corpus без необходимости.
2. Сопоставить их через Affinity Mapping или другой подходящий анализ.
3. Для каждого pattern сформулировать возможный механизм и альтернативы.
4. Проверить поддержку, противоречия и значение для Project Question.
5. Отделить insight от implication и принятого решения.
6. Передать нормализованные выводы в Research Synthesis ссылками.

### Limitations

- insight является интерпретированным выводом, а не сырым фактом;
- пересечение источников может быть мнимым, если они зависят от одного origin;
- выразительность формулировки не повышает доказательность;
- отсутствие противоречий может отражать узкую выборку.

## Граница владения

Метод хранит путь синтеза, insight cards и evidence. Research → Synthesis хранит согласованный нормализованный вывод с ограничениями. Core, Positioning и другие разделы принимают собственные решения, а не получают их автоматически из insight.
