# VISUAL SEGMENTATION — группировка визуального поля

[[Methods/METHODS_OVERVIEW|← Methods Overview]]

## Method Definition

### Purpose

Сгруппировать визуальный corpus по наблюдаемым признакам и устойчивым сочетаниям, чтобы описать территории поля, повторения, различия и неоднозначные границы.

### Categories

- Synthesis / Analysis

### Use When

- Reference Collection достаточно разнообразна для сравнения;
- нужно понять структуру визуального поля, а не выбрать понравившийся стиль;
- отдельные характеристики образуют повторяющиеся комплексы.

### Do Not Use When

- группы и их названия заданы до просмотра материала;
- редкость автоматически называется свободной территорией;
- принадлежность к сегменту основывается только на настроении без наблюдаемых признаков;
- сегментация используется как готовая Visual Identity.

### Required Inputs

- corpus с source metadata;
- Project Question и единица сегментации;
- начальный набор наблюдаемых признаков, допускающий пересмотр.

### Process

1. Описать материалы по наблюдаемым признакам: типографика, цвет, композиция, изображение, фактура, движение и другие релевантные параметры.
2. Сгруппировать сходные сочетания и отметить гибридные/неоднозначные объекты.
3. Дать каждой территории нейтральное рабочее название и описание функции.
4. Сравнить распространённость только внутри corpus и проверить source bias.
5. Сформулировать findings и вопросы для дальнейшего semiotic или perception research.

### Limitations

- сегменты являются исследовательской моделью и зависят от выбранных признаков;
- эстетическая близость не равна одинаковому позиционированию или восприятию;
- редкий сегмент не доказывает возможность или привлекательность;
- один объект может принадлежать нескольким территориям.
