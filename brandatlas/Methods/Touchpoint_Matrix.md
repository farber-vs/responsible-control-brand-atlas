# TOUCHPOINT MATRIX — сопоставление точек контакта

[[Methods/METHODS_OVERVIEW|← Methods Overview]]

## Method Definition

### Purpose

Сопоставить выбранные точки контакта по единым критериям, чтобы увидеть разрывы содержания, поведения, идентичности, доступности и переходов. Матрица является аналитическим представлением evidence, а не отдельным источником фактов.

### Categories

- Synthesis / Analysis
- Service / Experience
- Validation / Testing

### Use When

- точек контакта достаточно много для сравнительного обзора;
- нужно проверить сквозную согласованность нескольких сред;
- отдельные наблюдения уже собраны в Audit, CJM или иных источниках.

### Do Not Use When

- требуется восстановить последовательный путь человека — используйте CJM;
- критерии сравнения не связаны с Project Question;
- баллы назначаются без определённой шкалы и evidence.

### Required Inputs

- список точек контакта и ссылки на первичные наблюдения;
- выбранный сценарий, группа или период;
- критерии и, если используется оценка, явная шкала.

### Process

1. Задать вопрос и границы матрицы.
2. Выбрать только относящиеся к вопросу критерии.
3. Заполнить строки ссылками на evidence; неизвестное оставить неизвестным.
4. Сравнить точки, найти сквозные разрывы и исключения.
5. Передать нормализованные findings в соответствующие разделы ссылками.

### Limitations

- матрица упрощает контекст каждой точки;
- одинаковая оценка может скрывать разные причины;
- согласованность не равна эффективности;
- отсутствие материала не должно автоматически получать низкий балл.

## Граница владения

Первичные текущие наблюдения принадлежат [[01_Audit/05_Touchpoints|Audit → Touchpoints]] или другому указанному источнику. Матрица хранит их сравнительное представление и результат анализа. Целевые изменения принимаются в [[05_Service_System/03_Service_Journey|Service Journey]], Interaction Principles, External или другом относящемся к решению разделе.
