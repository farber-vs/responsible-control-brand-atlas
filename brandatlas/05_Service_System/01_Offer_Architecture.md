# OFFER ARCHITECTURE — архитектура предложения

## Контур

| Уровень | Компоненты | Результат |
|---|---|---|
| Knowledge | Evidence, clinical content, law, version | Независимое основание |
| Product | Паспорт, класс, форма, единица, партия | Технически различимый тип |
| Interface | Упаковка, карточка, каталог, знак | Сопоставимое чтение |
| Access | Канал, пространство, eligibility, выдача | Пропорциональная процедура |
| Support | Персонал, помощь, отказ, инцидент | Достойное действие |
| Accountability | Реестр, отзыв, жалоба, метрики | Проверяемость и изменение |

## Три идентичности

Регуляторный класс → продуктовый тип → производственная атрибуция. Производитель полностью видим регулятору и отзыву, но не получает consumer-brand зоны.

## Итог

> Предложение — не ассортимент брендов, а шесть связанных уровней от независимого знания до публичной подотчётности.
