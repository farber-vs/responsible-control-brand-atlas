# Presentation

## Файлы

- `responsible_control_presentation_system_v02.pptx` — каноническая редактируемая версия.
- `responsible_control_presentation_system_v02_figma.pptx` — транспортная версия для Figma Slides.
- [Figma Slides v0.2](https://www.figma.com/slides/4ckOw23Xz1ZuvSZUmmaPJ2/responsible_control_presentation_system_v02) — рабочий файл.

## Состав

55 слайдов: 24 кадра визуальной системы и структуры MVP + 31 solution frame для упаковки, пространства, печатных носителей, digital, сервиса и sensory.

Каждый будущий визуал задан через placeholder с четырьмя полями: объект, обязательный ракурс, техническое условие и функция кадра. Placeholder не является готовым решением и не задаёт lifestyle-стилистику.

Подробная карта и параметры находятся в [Presentation System](../Documentation/21_Presentation_System.md).
